# memory-proxy
OpenAI API互換のサーバーに対するプロキシサーバーです。  
全ての会話リクエストを傍受して、裏でデータベースへ蓄積します。  
このときベクトル化、ナレッジグラフ化が行われ、のちのリクエストで記憶として参照できるようにします。  
具体的には、リクエストが来るたびにプロンプトの末尾に記憶を足してからサーバーへ転送することで実現します。  
ただし、記憶の保存自体にLLMを使うため、一度のリクエストに対して内部では複数回生成が発生します。（少し待ち時間が増えます）

## スクリプト

### main.py
サーバーを起動します。

### bake.py
scenario.txtのファイルを使ってデータベースに記憶を書き込みます。

### search.py
search.txtのファイルを使ってデータベースから記憶を検索します。

### compress.txt
long_text.txtのファイルに書かれたテキストを要約します。
